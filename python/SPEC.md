# Fucking C 2.0 — спецификация

## 1. Лексика

Исходник — Unicode-текст UTF-8. Токены разделяются одним или несколькими пробельными символами. Перенос строки сам по себе не завершает инструкцию. BOM допускается и не является командой.

Перед распознаванием каждого токена кириллические `С` / `с` заменяются латинскими `C` / `c`, затем применяется NFC. Все остальные символы должны входить в конкретный распознаваемый токен. Неизвестные токены не игнорируются; комментариев нет.

Идентификатор: `ƈ[cC]+`. Полная нормализованная строка — имя; регистр значим. Число: `Ƈ[cC]+`, двоичная запись неотрицательного int (`c=0`, `C=1`); знак задаётся отдельным оператором. Строка: `Ȼ[cC]*`, число битов кратно 8, каждый байт записан старшим битом вперёд, результат должен быть корректным UTF-8. `Ȼ` без битов — пустая строка.

Сами `Ƈ`, `ƈ`, `Ȼ` — символы латинской C с крючком/штрихом, не произвольные буквы. В исходнике нет ASCII-цифр, кавычек, математических знаков или обычных буквенных слов.

### Значимые украшения

| Вид | Unicode |
|---|---|
| `C̄` / `c̄` | U+0304, macron |
| `C̈` / `c̈` | U+0308, diaeresis |
| `C̃` / `c̃` | U+0303, tilde |
| `C̲` / `c̲` | U+0332, low line |
| `C̶` / `c̶` | U+0336, long stroke overlay |
| `C̆` / `c̆` | U+0306, breve |
| `C̊` | U+030A, ring above |
| `Ć ć` | U+0106, U+0107 |
| `Ĉ ĉ` | U+0108, U+0109 |
| `Ċ ċ` | U+010A, U+010B |
| `Č č` | U+010C, U+010D |
| `Ç ç` | U+00C7, U+00E7 |
| `Ƈ ƈ` | U+0187, U+0188 |
| `Ȼ` | U+023B |

Разложенные аналоги `Ć`, `Ĉ`, `Ċ`, `Č`, `Ç` разрешены благодаря NFC. Внешне похожие, но не указанные украшения не являются псевдонимами.

## 2. Грамматика

Ниже имена LET/FN и прочие — **имена видов токенов в описании**, не разрешённые слова исходника. Их C-запись дана в README и команде `fc syntax`.

```text
program       = statement* EOF
statement     = LET IDENT ASSIGN expression SEMI
              | FN IDENT parameters block
              | IF condition block (ELSE (if-statement | block))?
              | WHILE condition block
              | FOR LPAREN IDENT IN expression RPAREN block
              | RETURN expression? SEMI
              | BREAK SEMI
              | CONTINUE SEMI
              | block
              | expression (ASSIGN expression)? SEMI
block         = LBRACE statement* RBRACE
condition     = LPAREN expression RPAREN
parameters    = LPAREN (IDENT (COMMA IDENT)* COMMA?)? RPAREN
primary       = NUMBER | STRING | TRUE | FALSE | NULL | IDENT | BUILTIN
              | LPAREN expression RPAREN
              | LBRACKET (expression (COMMA expression)* COMMA?)? RBRACKET
              | FN parameters block
postfix       = primary (call | index)*
call          = LPAREN (expression (COMMA expression)* COMMA?)? RPAREN
index         = LBRACKET expression RBRACKET
```

В левой части присваивания допускаются только имя или индекс. Присваивание — инструкция, не выражение. У функции максимум 255 параметров; при вызове максимум 255 аргументов. Повтор параметра — ошибка синтаксиса.

`return` допустим только внутри функции. `break` и `continue` — внутри собственного цикла: функция, определённая внутри чужого цикла, не получает доступ к управлению этим циклом. Эти условия проверяет парсер до выполнения.

## 3. Приоритеты выражений

От низкого к высокому:

| Приоритет | Операторы | Ассоциативность |
|---|---|---|
| 10 | `or` | Левая, короткое замыкание |
| 20 | `and` | Левая, короткое замыкание |
| 35 | `not` | Унарный |
| 40 | `== != < <= > >=` | Цепочка сравнений |
| 50 | `+ -` | Левая |
| 60 | `* / // %` | Левая |
| 70 | Унарные `+ -` | Унарная |
| 80 | `**` | Правая |
| 90 | Вызов и индекс | Слева направо |

`2 ** 3 ** 2 = 512`; `-2 ** 2 = -4`; `(-2) ** 2 = 4`. Отрицательная степень разрешена и может дать float. Комплексные числа не поддерживаются.

Цепочка `a < b <= c` вычисляет каждое нужное выражение ровно один раз. Если сравнение ложно, следующие выражения не вычисляются. `not a == b` означает `not (a == b)`.

## 4. Типы и операции

- **int:** целое со знаком; защитный предел — 4096 значащих двоичных разрядов. Не 8-битная ячейка.
- **float:** конечный binary64. `/` всегда даёт float. `//` округляет вниз, `%` согласован с этим делением. NaN и бесконечности отвергаются.
- **bool:** true/false. Не участвует в арифметике и не считается допустимым индексом. `true == 1` — false.
- **null:** отсутствие значения, в том числе неявный результат функции и EOF.
- **str:** неизменяемая Unicode-строка. Индекс и len считают кодовые точки, не байты и не графемные кластеры.
- **list:** изменяемая последовательность любых значений. Копирования при присваивании/передаче аргумента нет.
- **function:** вызываемое значение, замыкание или встроенная функция.

`+` работает с двумя числами, двумя строками или двумя списками. Для строк/списков это конкатенация; список копируется поверхностно. `*` поддерживает числа, а также повторение строки/списка целое число раз, с любой стороны. Нулевое/отрицательное повторение даёт пустое значение.

Равенство чисел учитывает значение при смешивании int/float. Для остальных типов разные типы не равны. Строки сравниваются по содержимому, списки — рекурсивно по содержимому; циклические списки допускаются. Функции сравниваются по идентичности. Сравнение порядка разрешено только для двух чисел или двух строк.

Ложные значения: false, null, числовой ноль, пустая строка, пустой список. Остальные истинные. `and`/`or` возвращают один из своих операндов, `not` — bool.

Индексация разрешена для строк и списков. `-1` — последний элемент; выход за границы — ошибка. Изменять по индексу можно только список. Срезов в версии 2.0 нет.

## 5. Области видимости и функции

`C имя Ç выражение ċ` создаёт имя в текущей области. Повторное объявление в этой же области — ошибка; во вложенной области допускается затенение. Объявления действуют после выполнения, предварительного поднятия объявлений нет.

Блок создаёт дочернюю область. Поиск и присваивание идут от текущей области к её родителям. Функция сохраняет ссылку на область своего определения, а не на область вызова. Родительские области продолжают существовать, пока их удерживают замыкания.

Захваченные области живые: последующие изменения и объявления в этой же области видны функции при вызове. Это поиск по сохранённой цепочке окружений, без отдельного статического разрешения имён и без temporal dead zone.

Каждый вызов создаёт область параметров; тело функции исполняется в ней. Аргументы вычисляются слева направо до вызова. Число аргументов должно совпадать с числом параметров. Передаются значения; списки и функции являются ссылочными значениями. Рекурсия и взаимная рекурсия работают, если необходимые объявления выполнены к моменту вызова.

`return` немедленно покидает функцию, в том числе из вложенного цикла. `return` без выражения и достижение конца тела возвращают null. Анонимная функция создаётся выражением `c Ć параметры ć Ĉ тело ĉ`.

Правая часть присваивания вычисляется до вычисления контейнера и индекса левой части. Встроенные функции доступны только для чтения.

## 6. Циклы

`while` проверяет условие перед каждым проходом; тело каждого прохода получает новую область блока. Присваивание внешним переменным сохраняется между проходами.

`for` принимает строку или список и перебирает его **снимок**, созданный в начале. Изменения исходного списка не добавляют новые проходы. Для каждого прохода создаётся отдельная область с переменной цикла, поэтому созданные внутри функции корректно захватывают отдельное значение прохода. Переменная цикла наружу не выходит.

`break` покидает ближайший цикл; `continue` начинает следующую проверку/итерацию. Для числовых диапазонов используется `range`, возвращающий список.

## 7. Ввод, вывод и ошибки

`print` выводит аргументы через один пробел и затем перевод строки. Строки выводятся без кавычек, элементы-строки внутри списка — в кавычках. True/false/null печатаются как `true`, `false`, `null`. Цикл в списке представляется как `[...]`.

`input` читает одну строку, удаляет её завершающий LF или CRLF, но сохраняет остальные пробелы. EOF возвращает null. Необязательная строка-подсказка печатается без перевода строки до чтения.

Ошибки не являются значениями и не имеют пользовательского `catch`. Лексическая/синтаксическая ошибка предотвращает исполнение всего файла. Ошибка выполнения останавливает текущий запуск; ранее выведенные данные остаются. В REPL после ошибки можно продолжить; уже совершённые изменения состояния не откатываются.

Координаты токенов хранятся по Unicode-кодовым точкам. Диагностика учитывает объединяющие диакритики при рисовании указателя. В стеке ошибки показывается до 12 мест вызовов.

## 8. Ресурсные границы реализации

- Исходник: 1 000 000 Unicode-символов.
- Целое число/литерал: до 4096 бит; ведущие нулевые биты литерала тоже входят в его лексический предел.
- Строка: 1 000 000 кодовых точек.
- Список и результат range: 100 000 элементов.
- Аргументы/параметры: 255.
- Шаги исполнения по умолчанию: 1 000 000.
- Глубина пользовательских вызовов по умолчанию: 128; глубина AST и значений дополнительно зависит от стека Python.
- Вывод по умолчанию: 1 048 576 байт UTF-8.

Шаги считаются при посещении инструкций и выражений AST, а также при проходах for; это не число символов и не число машинных инструкций. Установка большого `--max-depth` не отменяет ограничений стека Python. В REPL бюджет шагов/вывода обновляется для каждой завершённой команды.

Это ограничения удобства и защиты от случайного зависания, **не гарантия изоляции или безопасного выполнения недоверенного кода**.
