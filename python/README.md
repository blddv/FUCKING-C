# Fucking C 2.0 — язык, не сайт

**Высокоуровневый интерпретируемый язык с синтаксисом из вариаций C.**

Это не Brainfuck и не оболочка над ним: здесь собственный лексер, Pratt-парсер, AST-интерпретатор, переменные, типы, функции и области видимости. Веб-интерфейса в этом проекте нет. Реализация на Python 3.10+, без сторонних библиотек.

## Запуск

Распакуй архив и открой терминал в папке проекта:

```bash
python3 fc.pyz examples/factorial.fc
# 720

python3 fc.pyz examples/map.fc
# [1, 4, 9, 16]

python3 fc.pyz examples/closure.fc
# 1 2 3

python3 fc.pyz repl
```

**`fc.pyz` — весь интерпретатор в одном файле.** Для него нужен только Python 3.10+; установка пакета не требуется. На Windows можно использовать `py -3` вместо `python3`. Linux/macOS также могут запускать `./fc.pyz`, если разрешено выполнение.

Из исходников работает тот же CLI:

```bash
python3 fc.py examples/factorial.fc
python3 -m fucking_c examples/factorial.fc
```

Опциональная установка в своё виртуальное окружение:

```bash
python3 -m pip install .
fc examples/factorial.fc
```

## Возможности

- Динамические типы: `int`, `float`, `bool`, `null`, Unicode-строки, списки, функции.
- Именованные переменные, присваивание, вложенные области видимости.
- Арифметика с приоритетами, сравнения и логические операции с коротким замыканием.
- `if / else`, `while`, `for / in`, `break`, `continue`.
- Именованные и анонимные функции, параметры, `return`, рекурсия, замыкания.
- Функции можно передавать аргументами, возвращать и хранить в списках.
- Изменяемые списки, вложенные списки, индексирование, отрицательные индексы.
- `print`, `input`, `len`, `append`, `pop`, `range`, преобразования типов, `assert`.
- REPL с сохранением переменных между командами.
- Ошибки с именем файла, строкой, столбцом, указателем и цепочкой вызовов.
- Проверка синтаксиса без исполнения и просмотр токенов.

## Настоящая программа: рекурсивный факториал

Файл `examples/factorial.fc`:

```text
c ƈC Ć ƈc ć Ĉ
    CC Ć ƈc C̲C ƇC ć Ĉ
        cC ƇC ċ
    ĉ
    cC ƈc C̈ ƈC Ć ƈc c̄ ƇC ć ċ
ĉ

C̶ Ć ƈC Ć ƇCCc ć ć ċ
```

Эквивалент обычными словами — **это пояснение, не альтернативный синтаксис**:

```text
fn factorial(n) {
    if (n <= 1) { return 1; }
    return n * factorial(n - 1);
}
print(factorial(6));
```

`ƈC` — имя функции, `ƈc` — имя параметра, `ƇC` — число 1, `ƇCCc` — число 6.

## Основные команды

**Каждый токен отделяется пробелом, табом или переносом строки, включая скобки и операторы.** Комментариев в `.fc` нет: значимые символы исходника остаются C-вариациями. Пробельные символы нужны только как разделители.

### Конструкции

| Fucking C | Обычный смысл |
|---|---|
| `C` | `let`: объявить переменную |
| `c` | `fn`: объявить функцию или создать анонимную |
| `CC` / `cc` | `if` / `else` |
| `Cc` | `while` |
| `CCC` / `CCc` | `for` / `in` |
| `cC` | `return` |
| `CcC` / `Ccc` | `break` / `continue` |
| `Ć` / `ć` | `(` / `)` |
| `Ĉ` / `ĉ` | `{` / `}` — блок |
| `Č` / `č` | `[` / `]` — список или индекс |
| `Ċ` | `,` — разделитель аргументов/элементов |
| `ċ` | `;` — конец инструкции |
| `Ç` | `=` — присваивание |

### Операторы и константы

| Fucking C | Смысл |
|---|---|
| `C̄` / `c̄` | `+` / `−`, также унарные |
| `C̈` / `c̈` | `*` / `/` |
| `c̃` / `C̃` | `//` / `%` |
| `C̈C` | `**` — степень |
| `ÇÇ` / `çç` | `==` / `!=` |
| `C̲` / `C̲C` | `<` / `<=` |
| `c̲` / `c̲c` | `>` / `>=` |
| `cCC` / `cCc` / `ccC` | `and` / `or` / `not` |
| `C̆` / `c̆` / `C̊` | `true` / `false` / `null` |

### Имена, числа и строки — тоже только C

- **Имя:** `ƈ` + одна или несколько `c`/`C`. Например, `ƈC`, `ƈc`, `ƈCC` — три разных имени. `ƈ` — строчная C с крючком.
- **Целое число:** `Ƈ` + двоичная запись, где `c = 0`, `C = 1`. `Ƈ` — прописная C с крючком. Примеры: `Ƈc = 0`, `ƇC = 1`, `ƇCc = 2`, `ƇCCc = 6`, `ƇCcCcCc = 42`. Минус — отдельный оператор: `c̄ ƇCC` означает −3.
- **Строка:** `Ȼ` + байты UTF-8, записанные теми же битами `c`/`C`. `Ȼ` — C с косой чертой. Пустая строка — просто `Ȼ`. Буква `C` — `ȻcCccccCC`.
- **Float:** получается при `/` или через встроенную `float`. Отдельной десятичной записи в исходнике нет, иначе в алфавите появились бы цифры. Например, `Ć ƇCcC c̈ ƇCc ć` — 2.5.

Чтобы не кодировать текст и большие числа вручную:

```bash
python3 fc.pyz literal int 42
# ƇCcCcCc

python3 fc.pyz literal float 2.5
# Ć ƇCcC c̈ ƇCc ć

python3 fc.pyz literal str 'Привет, C!'
python3 fc.pyz literal name counter
```

`literal name` кодирует имя из обычного текста в C-идентификатор. Короткие имена вроде `ƈC` можно просто придумывать самостоятельно. `literal float` создаёт выражение с точным двоичным значением конечного 64-битного float.

**В данных ограничений на алфавит нет:** ввод, вывод и значения строк могут содержать русский текст, эмодзи, цифры и любую другую Unicode-информацию. C-only ограничение относится к написанию исходника.

## Переменные и списки

```text
C ƈC Ç ƇCcCcCc ċ
ƈC Ç ƈC C̄ ƇC ċ
C̶ Ć ƈC ć ċ
```

Выведет `43`. Это обычная переменная, а не ячейка байтовой ленты.

```text
C ƈC Ç Č ƇC Ċ ƇCc Ċ ƇCC č ċ
C̶c Ć ƈC Ċ ƇCcc ć ċ
ƈC Č Ƈc č Ç ƇCcCc ċ
C̶ Ć ƈC ć ċ
```

Выведет `[10, 2, 3, 4]`: создали список, добавили 4 и заменили элемент 0.

## Встроенные функции

Вызов: `имя Ć аргумент Ċ аргумент ć`.

| Имя | Сигнатура | Поведение |
|---|---|---|
| `C̶` | `print(...)` | Вывод через пробел с переводом строки, результат `null` |
| `c̶` | `input([prompt])` | Прочитать строку без завершающего перевода; EOF → `null` |
| `C̶C` | `len(value)` | Число Unicode-кодовых точек строки или элементов списка |
| `C̶c` | `append(list, value)` | Добавить элемент, результат `null` |
| `C̶CC` | `pop(list[, index])` | Удалить и вернуть элемент; по умолчанию последний |
| `C̶Cc` | `str(value)` | Строковое представление |
| `C̶cC` | `int(value)` | Десятичная строка/число/bool → int; float усекается к нулю |
| `C̶cc` | `float(value)` | Строка/число/bool → конечный float |
| `C̶CCC` | `range(stop)` / `range(start, stop[, step])` | Список целых, граница stop не включается |
| `C̶CCc` | `type(value)` | Строка `int`, `float`, `bool`, `null`, `str`, `list` или `function` |
| `C̶CcC` | `assert(condition[, message])` | Ошибка, если условие ложно; иначе `null` |

## CLI и REPL

```bash
python3 fc.pyz run examples/factorial.fc --stats
python3 fc.pyz check examples/factorial.fc
python3 fc.pyz tokens examples/factorial.fc
python3 fc.pyz syntax
python3 fc.pyz examples/echo.fc --input 'Привет!'
python3 fc.pyz repl
```

В REPL можно писать многострочные блоки. `.help` показывает таблицу токенов, `.quit` завершает работу. Для отдельного выражения завершающую `ċ` можно опустить; результат будет напечатан. Команды REPL и параметры CLI — инструменты, а не синтаксис `.fc`.

Для `run` доступны `--max-steps N`, `--max-depth N`, `--max-output N`. `--input TEXT` заменяет stdin. Без него `input` читает настоящий stdin, включая интерактивный ввод. Статистика и ошибки идут в stderr, данные программы — в stdout. Код возврата: `0` — успех, `2` — ошибка синтаксиса/аргументов, `1` — ошибка выполнения/ресурсов/файла, `130` — прерывание.

## Семантика и ограничения

Подробности — в **[SPEC.md](SPEC.md)**. Кратко:

- Нет переполнения по модулю 256: целые числа растут до защитного лимита 4096 бит. Float — конечный IEEE 754 binary64.
- Типы не склеиваются неявно: строка + число — ошибка; bool не участвует в арифметике. `int` и `float` можно смешивать.
- Строки неизменяемы, списки передаются по ссылке. Индексы начинаются с 0, отрицательные считаются с конца.
- Функция захватывает окружающую область, а не область вызывающего кода. Присваивание меняет ближайшее уже объявленное имя.
- Объявления исполняются последовательно. Вызов функции без return даёт `null`.
- `for` перебирает снимок списка/строки; каждый проход получает отдельную локальную переменную.
- Ключевые токены нормализуются в NFC; кириллические `С/с` принимаются вместо латинских `C/c`.
- По умолчанию: 1 000 000 шагов, 128 вложенных вызовов, 1 МиБ вывода. Глубокая вложенность AST также ограничивается возможностями Python-реализации.
- Это первая реализация небольшого языка, не промышленный компилятор: нет модулей, классов, FFI, файлового API или пользовательских обработчиков исключений. Защитные лимиты не превращают интерпретатор в изолированную среду для недоверенного кода.

## Исходники и тесты

```bash
python3 -m unittest discover -s tests -v
python3 build.py
```

Тесты охватывают лексер, AST, типы, приоритеты, Unicode, изменяемые списки, рекурсию, замыкания, области видимости, циклы, ошибки, лимиты, CLI и REPL. Включены 200 детерминированных случайных арифметических деревьев с независимым вычислением ожидаемого результата.

```text
fc.pyz                  готовый автономный CLI
fc.py                   запуск из исходников
fucking_c/lexer.py      токенизатор и кодирование литералов
fucking_c/parser.py     AST и Pratt-парсер
fucking_c/runtime.py    интерпретатор, области видимости, встроенные функции
fucking_c/errors.py     диагностика и стек вызовов
fucking_c/cli.py        команды терминала и REPL
examples/               восемь программ .fc
tests/                  тесты стандартной библиотекой unittest
SPEC.md                 грамматика и семантика
build.py                сборка одного файла fc.pyz
pyproject.toml          опциональная установка команды fc
```

В этой версии нет ни HTML, ни JavaScript, ни сервера. С прежней байтовой Brainfuck-подобной версией синтаксис несовместим.
